# From Chords to Code: Building a Ukulele Companion App

Slides for my talk at [FOSSMeet 2026](https://fossmeet.in/), NIT Calicut.

## Abstract

This talk shares the journey of building a ukulele companion app -- from a simple personal need to a published mobile application used by real users. It explores how a music-learning idea evolved into a functional app, covering key decisions in design, architecture, and feature development.

## Building the Slides

Requires a TeX Live installation with Beamer and the Metropolis theme.

```
make        # Build slides.pdf
make clean  # Remove generated files
```
